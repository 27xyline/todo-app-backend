# Тесты

Установите зависимости разработки командой `uv sync`, настройте `DATABASE_URL`
и `CORS_ORIGINS` в `.env` (пример — в `.env.example`) и запустите PostgreSQL.
Затем выполните:

```bash
uv run pytest
```

Тесты автоматически создают на том же сервере отдельную базу, добавляя `_test`
к имени из `DATABASE_URL`. Пользователю PostgreSQL нужно право создавать базы
(`CREATEDB`) и подключаться к базе `postgres`. Тестовая база сохраняется между
запусками; таблицы создаются при необходимости, данные каждого теста
откатываются. Рабочая база не используется для тестов.
